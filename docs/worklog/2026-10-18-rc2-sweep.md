## 再開のしかた（途中で止まったとき）

道具は `tools/rc2_sweep/`。作業の出力は `target/rc2-sweep/`（git に入れない）。

```
cargo build --release -p sabiruby-cli
python3 tools/rc2_sweep/sweep.py lists              # 両方の VM からメソッドの一覧（Docker）
python3 tools/rc2_sweep/sweep.py cases              # 呼び出しの表とその数（VM は走らせない）
python3 tools/rc2_sweep/sweep.py run --timeout 5    # 全部（--only '受け手の正規表現' で一部だけ）
python3 tools/rc2_sweep/compare.py                  # 分類 → target/rc2-sweep/x1-diffs.tsv と docs の縮めた表
python3 tools/rc2_sweep/programs.py run --timeout 60
python3 tools/rc2_sweep/programs.py compare         # → docs/verification/rc2-sweep/x2-*.tsv
```

`run` は受け手ごとの塊（chunk）を両側で走らせ、`target/rc2-sweep/raw/{ref,sabi}/<受け手>.tsv` に 1 呼び出し 1 行で書く。
途中の塊は消して `--only` でやり直せばよい。
